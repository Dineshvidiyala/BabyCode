# IELTS Masters - Institute Homepage

A modern, responsive homepage for a fictional IELTS preparation institute built with React, TypeScript, and Tailwind CSS.

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ installed
- npm or yarn package manager

### Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd ielts-masters-homepage
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Open in browser**
   Navigate to `http://localhost:5173`

### Build for Production
```bash
npm run build
npm run preview
```

## 🎨 Design Choices

### Overall Approach
- **Modern & Professional**: Clean design with a focus on trust and credibility
- **Education-Focused**: Color scheme and imagery that resonates with learning
- **Conversion-Oriented**: Strategic placement of CTAs and social proof

### Design Elements
- **Color Palette**: 
  - Primary: Blue (#3B82F6) - represents trust and professionalism
  - Secondary: Gradients and accent colors for visual interest
  - Neutral grays for text and backgrounds

- **Typography**: 
  - Clean, readable fonts with proper hierarchy
  - Bold headings for impact
  - Comfortable line spacing for readability

- **Layout**: 
  - Grid-based responsive design
  - Consistent spacing using 8px system
  - Strategic use of white space

### Responsiveness Strategy
- **Mobile-First**: Designed for mobile devices first, then scaled up
- **Breakpoints**: 
  - Mobile: < 768px
  - Tablet: 768px - 1024px  
  - Desktop: > 1024px
- **Flexible Grids**: CSS Grid and Flexbox for adaptable layouts

### Component Architecture
- **Modular Design**: Each section is a separate component
- **Reusable Elements**: Consistent button styles, cards, and layouts
- **Clean Code**: Well-structured, commented, and maintainable

### User Experience Features
- **Smooth Scrolling**: Navigation links scroll to sections
- **Hover Effects**: Interactive elements with subtle animations
- **Visual Hierarchy**: Clear information architecture
- **Social Proof**: Testimonials, statistics, and success indicators

## 📱 Responsive Features

- **Mobile Navigation**: Hamburger menu for mobile devices
- **Flexible Grid**: Adapts from 1 to 4 columns based on screen size
- **Scalable Text**: Font sizes adjust for optimal reading
- **Touch-Friendly**: Buttons and links sized for mobile interaction

## 🛠 Tech Stack

- **React 18** - Modern React with hooks
- **TypeScript** - Type safety and better development experience
- **Tailwind CSS** - Utility-first CSS framework
- **Lucide React** - Modern icon library
- **Vite** - Fast development and build tool
